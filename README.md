# 🌐 Mon Portfolio Personnel

🔗 **Lien du site en ligne :** [https://chlomartin45.github.io/](https://chlomartin45.github.io/)

---

## 🛠️ Technologies utilisées

* **HTML5** : Structure du site et accessibilité.
* **CSS** : Design moderne, responsive (adapté aux mobiles) et animations.

---

## 🚀 Fonctionnalités

* Présentation de mon parcours et de mes compétences.
* Vitrine de mes projets personnels et professionnels.
* Section contact avec liens vers mes réseaux (LinkedIn, GitHub).
* Intégration de mon CV téléchargeable.

---

## 📂 Structure du projet

* `index.html` : Page principale du site.
* `style.css` : Feuilles de style pour le design.
* `/assets` : Contient mon CV au format PDF et les dossiers finalisés.
